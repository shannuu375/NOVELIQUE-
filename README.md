🌷 The Paper Garden – Online Bookstore

📚 A Reading Space for Book Lovers

Welcome to The Paper Garden, a beautiful and user-friendly online bookstore designed for book lovers. Discover your next favourite book, explore different categories, find popular authors, and enjoy a wonderful reading experience.

🌸 About the Project

The Paper Garden is a responsive online bookstore website developed using HTML and CSS. It provides a simple and attractive platform for users to explore books and discover new stories.

✨ Features

- 🏠 Home Page
- 📚 Book Categories
- ⭐ Featured Books
- ✍️ Authors Section
- 🎁 Special Offers
- 🛒 Shop Now Section
- 🎨 Attractive and User-Friendly Design
- 📱 Responsive Layout

🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts

🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in your browser.
4. Explore The Paper Garden website!

🎯 Project Goal

To create a visually appealing online bookstore that makes discovering and exploring books simple, enjoyable, and accessible.
